# Singles Club SaaS PWA v1.0.0

Single-page, premium, app-like local singles club PWA.

## Included
- One-page SaaS layout
- Pulsing local activity map
- Automatically scrolling live feed
- $99 / $299 / $599 membership pricing
- One-time event prices
- Three-step application modal
- Photo preview
- Stripe, Zelle, QR, and on-site payment
- Chinese / English
- PWA install and offline shell
- Organization, WebSite, and Event structured data

## Configure
Edit `config.js` for brand, URL, city, contact, events, posts, plans, and payment details.

Replace `https://example.com/` in `robots.txt` and `sitemap.xml`.
