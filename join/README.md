# LivingHub Member Join v1.1.1 — Standalone

独立会员接龙与会员发现入口。

## v1.1.1 修复

- 注册成功后，当前真实注册会员会立即出现在“发现会员”最顶部。
- 当前会员资料卡标记为 `真实会员 · MY PROFILE`。
- 可以从真实会员卡直接进入“我的资料”修改个人信息。
- 修改资料后，会员卡同步刷新。
- 联系方式仍然不在公开卡片中显示。
- 案例资料继续明确标记为 `案例观察 · DEMO`，不会冒充真实会员。

## 当前限制

当前仍是前端独立版，资料保存在当前浏览器 localStorage。
因此：
- 你自己注册后可以马上看到自己的真实资料卡；
- 其他设备注册的人不会自动出现在你的设备上；
- 要让“所有真实注册会员都能互相看到资料”，必须接入中央数据库/认证服务。

下一步建议：保持当前界面不变，接 Supabase 或现有 LivingHub 数据层。
