# LivingHub Member Join v1.1 — Standalone

独立接龙式入会和会员发现入口。

## v1.1 changes

- 不在页面公开解释推荐结构。
- 免费登记后直接进入会员区。
- 会员区包含：发现会员 / 我的资料 / 我的邀请。
- 首页内置一组明确标记为“案例观察 · DEMO”的示例资料，让冷启动页面看起来有内容，但不会冒充真实会员。
- 示例资料联系方式永远隐藏。
- 真实会员资料在生产版中应根据付费状态、会员权限和对方隐私设置决定可见范围。
- 会员可以登录后编辑自己的昵称、城市、年龄、联系方式、介绍和兴趣。
- 联系方式不在公开卡片中直接展示。
- 个人邀请二维码和 Living Points 保留。

## Important

当前版本仍是独立前端原型，资料保存在本机 `localStorage`。
要实现：
- 后台查看全部会员
- 跨设备登录
- 真实会员目录
- 付费后解锁
- 会员之间受权限保护的联系方式
- 真实积分账本

需要下一步接 Supabase 或现有后端。
