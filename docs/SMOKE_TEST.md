# Production Smoke Test

1. Open the public frontend.
2. Confirm map nodes rotate automatically.
3. Click every map node and confirm the application dialog opens with the matching event selected.
4. Select each membership option and confirm the application dialog opens with the matching plan.
5. Submit a test application with and without photos.
6. Confirm an application number is returned.
7. Query the application with its original contact information.
8. Open the merchant administration entry and sign in.
9. Confirm events, posts, plans, applications, and settings load.
10. Change one event or post and confirm the public frontend updates.
