# Deployment Check

1. Upload this package to the root of the `singles-club` repository.
2. Delete old `public/`, `supabase/`, `render.yaml`, `service-worker.js`, `admin.html`, and `admin.js` files if present.
3. Confirm `config.js` points to:
   `https://singles-club-backend.onrender.com`
4. GitHub Pages must use `main` and `/ (root)`.
5. Open the frontend in a private browser window after deployment.
6. Submit a test application.
7. Confirm the application appears in the Render merchant admin.
